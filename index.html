01 · Contenido del proyecto

Proposito de la auditoria

El Controlador de Dominio concentra identidades, autenticación Kerberos y control de acceso. Una configuración débil puede poner en riesgo las cuentas y servicios de todo el dominio.

🖥️

Activo evaluado

Microsoft Windows Server 2025 Standard x64, con rol AD DS y DNS integrado, ejecutado en VMware Workstation Pro.

📘

Marco de referencia

CIS Microsoft Windows Server 2025 Benchmark v2.1.0, perfil Level 2 – Domain Controller Server.

🧪

Entorno controlado

Máquina virtual aislada mediante adaptador de red Host-Only y uso de instantáneas para preservar estados.

Alcance: se evaluaron 10 controles. El documento excluye estaciones cliente, otros roles no instalados, integraciones de identidad en la nube y auditoría del hardware físico.

04 · Consideraciones para la realización

Metodología de auditoría y remediación

Proceso secuencial, automatizado y verificable, con comparación entre la configuración inicial y la final.

Inspección de línea base

Se ejecutó Auditoria_Pre.ps1 con privilegios administrativos y se recopilaron evidencias de configuración inicial.

Identificar brechas

Remediación automatizada

Se ejecutó Remediacion_Hardening.ps1 para aplicar ajustes de registro, deshabilitar servicios/protocolos y activar auditoría.

Aplicar controles

Verificación posterior

Auditoria_Post.ps1 repitió las comprobaciones; también se revisaron consolas administrativas y continuidad de AD DS/DNS.

Validar y evidenciar

Preservación del entorno

Se documentaron dos instantáneas en VMware: 01_Baseline_PreAuditoria y 02_Post_Remediacion_Hardened, para comparar la línea base y el estado endurecido.

Conclusión

El endurecimiento preventivo basado en CIS reduce configuraciones inseguras, limita servicios innecesarios y mejora la capacidad de investigar eventos. En el alcance reportado, la verificación posterior registró conformidad en los diez controles evaluados.

El 100 % corresponde exclusivamente a la muestra de diez controles de este proyecto; no representa una certificación integral de toda la infraestructura.
